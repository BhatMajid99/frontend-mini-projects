# frontend-mini-projects
A collection of beginner-friendly frontend projects built using HTML, CSS and JavaScript to practice web development skills and improve problem-solving through real projects.

## Projects

### 1. Spotify Clone 🎵

A simple Spotify Web Player UI clone built using HTML and CSS.

#### Features

* Sidebar navigation
* Sticky top navigation
* Music cards section
* Bottom music player UI
* Album details and playback controls
* Dark theme inspired by Spotify

#### Tech Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts
