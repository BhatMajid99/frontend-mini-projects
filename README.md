# 🚀 Frontend Mini Projects

A collection of beginner-friendly frontend projects built using **HTML, CSS, and JavaScript** to practice web development skills and improve problem-solving through real projects.

---

## 📂 Projects

### 🎵 1. Spotify Clone

A simple Spotify Web Player UI clone built using HTML and CSS.

#### ✨ Features

* Sidebar navigation
* Sticky top navigation
* Music cards section
* Bottom music player UI
* Album details layout
* Dark theme inspired by Spotify

#### 🛠 Tech Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts

#### 🌐 Live Demo

👉 https://bhatmajid99.github.io/frontend-mini-projects/Spotify-clone

---

### 📚 2. FocusFlow (Landing Page)

A modern productivity web app landing page designed for students to visualize a focus and study management tool.

#### ✨ Features

* Clean and modern UI design
* Fully responsive design (mobile, tablet, desktop)
* Sections for features, about, and contact
* Smooth layout and structured content
* Call-to-action buttons

#### 🛠 Tech Used

* HTML5
* CSS3
* JavaScript (basic interactivity)

#### 🌐 Live Demo

👉 https://bhatmajid99.github.io/frontend-mini-projects/2.FocusFlow
